## B. Astra's amendment list (verbatim, `scc_r18_astra_final.md`)

I would close the S3 design with the following amendments. The first four items retain the round-7 P1 numbering. I reviewed `wt_main` at `18a5f5e` read-only. The tests below are acceptance criteria for implementation. I did not run them or measure corpus counts.

### P1 — correctness

1. **P1-1 · Direction-flag discharge — PRE-EXISTING.** `normalize.py:2429–2446` accepts a direction-flag debt based on the register span. It can therefore turn `cld; syscall; …; rep stosb` into an exact forward write, although the premise in `assumptions.py:95` does not cover a kernel return. `call_clobber.py:119` identifies the producing call.  
   **Rule.** Apply `direction-flag-clear` only if every origin of the relevant DF bytes on every reaching path is an entry or return covered by that premise. A kernel return, a wrapper forwarding its unknown DF, or an unidentified origin cannot discharge the debt. A subsequent definite DF write supersedes earlier origins on the paths it covers.  
   **Test.** With count two and known destination, the sequence above cannot establish a write at `dst+1`. A subsequent `cld` establishes forward direction and `std` establishes backward direction. Repeat through a wrapper and a join where only one arm executes `cld`.

2. **P1-2 · Byte detection precedes every semantic interpretation.** R17:19–29 makes detection depend on bundle-wide S1 and row length, although S1 is per function and length can be absent. Its prefix grammar also misses `48 66 0F 05` and repeated REX. A missed row can become a numeric marker or delta-proof input. `_scope_observation.py:244`, `pcodeop_models.py:57`, `register_delta_proofs.py:158–165`.  
   **Rule.** On an applicable sealed image with S3 ON, inspect every observed instruction **start**, independently of S1, declared length and lifting. Read initialized bytes in the same address space until a decisive mismatch, a match, or the architectural 15-byte limit. Recognize any ordering or repetition of the listed legacy and REX prefixes followed by either opcode. Do not search instruction interiors, bridge gaps or wrap addresses. Missing bytes before a decision mean `kernel-bytes-unavailable`; a decisive mismatch needs no further bytes. Only an unprefixed, length-two match with per-function S1 can be admitted. Every match takes precedence over markers, traps, intrinsics, call discovery, proof replay and premise reporting. An additional reviewed lifting is selected by its shape, without a producer-identity condition. Explicit bundle-less analysis is *not evaluated*. A sealed inapplicable image is *inapplicable*. OFF performs no S3 reads or suppression.  
   **Test.** Exercise both opcodes with missing and falsely short lengths, mixed S1, both prefix orders, repeated REX, a truncated prefix, a final-byte NOP, and opcode bytes inside another instruction. Try `CALLOTHER(17)`, `COPY`, `CALL`, and empty liftings. Only the valid bare shape acquires S3 semantics. Verify OFF retains the original marker and x86-32 `int 2e` is inapplicable.

3. **P1-3 · Refusal retains identity and caller obligations — PRE-EXISTING for retained failures with a trustworthy entry.** Strict admission can abort the run, while retained failures disappear before call discovery. A caller’s constant can consequently become complete. Local bindings and model cuts also run before the shared template check. `summary_engine.py:149,408–412`, `interprocedural.py:679–717,1170–1216,2778`, `control_context.py:134`.  
   **Rule.** Make S3 refusal a typed per-function result **after structural admission and before normalization** in both entry modes. Retain the verified entry, failure reason, and own sink failures. Install `control:unavailable:<callee>` and the resulting continuation obligation before binding, cut selection, activation and SCC solving. Carry them through direct, resolved indirect, mixed-target, tail and transitive calls, including register-free callers. A refused alternative stays in a target set. A local binding or wrapper cut must preserve these obligations and any admitted S3 support it would hide, or be ineligible. Apply the same unavailable rule to existing retained failures when their entry is independently trustworthy. Preserve values and origins that remain computable, and continue unrelated functions.  
   **Test.** In both modes, a caller’s literal after a refused callee retains its value and origin and reports unavailable control and conditional continuation. Repeat through a cut wrapper, an indirect set with one healthy target, a conditional tail, a cycle, and a jump-only caller. The refused function reports its failure and an unrelated sink remains complete.

4. **P1-4 · Stack-switch evidence must cover the whole program — PRE-EXISTING in the Python and Java transfers.** A sparse missing register can act like coefficient zero, the Python caller can fall back to nonvolatile RBX when its leaf check declines, and the Java scanner can certify clean code outside the selected closure. `may_alias.py:1526,1616–1647`, `_stack_preservation.py:38`, `interprocedural.py:2663–2711`, `ghidra/GhidraV2StackSwitchScan.java:133,392`, `stack_evidence.py:37,121`, `linking.py:435–465`.  
   **Rule.** At an admitted site preserve exactly the evidenced RSP value. Make all other register bytes unknown, including partial aliases and registers first read later. Across a callee that may execute S3, require independent preservation evidence before reusing a saved stack value. Apply this through wrappers, tails and unresolved alternatives. The program scan includes cut and refused functions. A reachable S3 refusal or an uncovered kernel transfer is a possible switch. The Java whole-program scanner must implement the same conservative transfer or report the affected code unchecked. Bind clean evidence to scanner semantics, input identity and effective policy. Withdraw or regenerate incompatible clean evidence in analysis, linking and derivation.  
   **Test.** Use `mov rbx,rsp; syscall; mov rsp,rbx`, a first-read `add rsp,rbx`, partial RBX writes, and one- and two-wrapper variants. Place the only switch outside the selected closure and then in a refused function. Each withdraws globals/stack disjointness. An old clean scan cannot reinstate it. A freshly established independent stack value still works.

5. **P1 · Admission requires affirmative flow and RSP evidence.** The exporter serializes `FlowType.isOverride()`, while its actual instruction override check is on a different path. Validated targets can lose an external target, and some analysis paths infer register space from raw operands. `ghidra/GhidraV2BundleExport.java:1431,2079,2145`, `_scope_observation.py:545`, `isa_identity.py:65`, `interprocedural.py:1186`.  
   **Rule.** Require sealed evidence of no instruction-level override, retain the raw external-target indicator, and require one local same-space fallthrough at `address+2`, consistent flow flags, no competing normal or recorded exceptional target, and no listed fallthrough exit. Missing override evidence needs an equivalent verified attestation or a named evidence refusal. Require a nonempty constant selector/input list and the exact r16 operand, output and width checks. Resolve the unique eight-byte **RSP** and its register space from verified register evidence even in a body with no raw register operand.  
   **Test.** Reject an actual instruction override with otherwise plausible flags, a dropped external target, a conflicting terminal flag, a wrong-space successor at the right offset, an empty selector list, and missing RSP evidence. Admit a register-free body with valid RSP evidence and a valid bare syscall with no recorded exception target.

6. **P1 · Normalize the pair atomically across register and memory consumers.** `preserves_memory=False` alone does not create an unbounded writer, and UNIQUE storage is function-scoped. An ordinary `CALLIND` seed or stale first-op temporary can survive a partial implementation. `normalize.py:1354,1923–1995`, `storage.py:149`, `call_clobber.py:336–352`, `write_classes.py:50–75`, `forward.py:418`.  
   **Rule.** Reserve both raw keys of the pair. Install one placed effect keyed by the `CALLIND`, or by the sole `CALLOTHER` for the bare form. Suppress the ordinary call seed, target, temporary value and stack adjustments. Require the consumed UNIQUE bytes to be dead until redefinition, or model later reads as unknown. Install one explicit unbounded **may-write** of RAM with the canonical operation key. Give writer classifiers the site decision and writer key. Use that identity in normalization, B′, forward queries, state barriers, alias certificates and exit summaries. Retain RSP at the site, unknown site restoration, and uncertainty for every potentially affected RAM byte until independently overwritten.  
   **Test.** For both encodings, compare dense, sparse and χ paths, forward probes and exit summaries. A pre-site constant in RAM loses certainty, a later one-byte store recovers only that byte, and an intervening S3 defeats a memory certificate. Check a later read and a later redefinition of the pair temporary. Require one writer, one effect, no synthetic graph edge, and an unknown saved return target even when the later `ret` stack delta is computable.

7. **P1 · Call-clobber discharge must prove the right bytes through the exit — PRE-EXISTING.** The transfer unions call origins and takes the hull of dirty bytes. The configured preservation checker traces terminal writes and debts on reads, which can miss a later clobber with no subsequent read. `call_clobber.py:398–416`, `_call_clobber_sparse.py:241–256`, `integration/configured_call_clobber_discharge.py:563,608–636`.  
   **Rule.** Retain exact `(producing call, byte interval)` evidence for origin-sensitive discharge. A preservation or must-write certificate must cover every claimed byte at every relevant exit, including intervening calls and outstanding control obligations after the last candidate definition. An aggregate read record alone cannot license discharge.  
   **Test.** Cross two calls with different preserved subspans and overwrite a middle byte. Check each surviving debt’s producer and interval. Restore a register, call an opaque callee, then return without rereading it: no preservation certificate. Move the proven restore after the last clobber and recover the certificate.

8. **P1 · Withdrawing stack disjointness must reach its proof consumers — PRE-EXISTING.** The configured frame checker skips absolute writes as globals. The leaf checker also compares a raw register-space ID with the canonical register-file key, which storage resolution sets to zero. `integration/configured_call_clobber_discharge.py:539–540`, `_stack_preservation.py:94–132`, `storage.py:166–177`.  
   **Rule.** Frame, saved-copy and out-parameter proofs may exclude a fixed-address write from a stack interval only with active disjointness or independent non-alias evidence. In leaf preservation, compare raw outputs and requested bytes in the same validated register coordinate system. Missing terminal coverage of an overlapping output yields no identity proof.  
   **Test.** Withdraw disjointness via a switch in another function, then query a helper writing a fixed address that can coincide with the caller’s stack. Its frame certificate must fail. Use a nonzero exported register-space ID and an overlapping leaf output missing from terminal coverage. It must not certify identity.

9. **P1 · Refusal must retain fault-analysis hazards — PRE-EXISTING for unresolved caller edges.** The fault caller graph can drop a wildcard. Removing a refused or cut caller can then turn absence of a known hazardous caller into a fault discharge. `fault_premise.py:114,164–197,294`, `control_context.py:169–202`.  
   **Rule.** Retain independently observed caller edges and hazards from refused and cut functions. Where an unresolved edge could connect a hazardous caller to a faulting callee, keep the fault conditional. A contradictory kernel lifting supplies neither a real call target nor a numeric transactional marker.  
   **Test.** Give a refused function an independent exception or transactional hazard and a genuine direct, then indirect, call to a faulting function. The fault stays conditional in both cases. A fabricated `CALL` in the rejected row creates no edge.

10. **P1 · Proofs and activation replay must preserve the site decision.** A fingerprint bump protects stored receipts, but replay rebuilds normalizer inputs and a composed effect can hide its producing site. `register_delta_proofs.py:147,184,248,294`, `_call_activation.py:145–166`, `function_summary.py:384`, `return_relations.py:419,579`.  
    **Rule.** Pass the same verified decision, effect and premise registry through initial normalization, activation, fallback and replay. Reject a register-delta proof whose derivation depends on a kernel return or unavailable continuation, directly or through a composed callee, alternative, tail or SCC. Include the dependency in receipt identity. An unrelated `memory-writes` key alone keeps its existing semantics. The local continuation carries its kernel-return support wherever it is used.  
    **Test.** Attempt direct, wrapper, multi-target and cyclic delta proofs before and after activation and receipt reload. All kernel-dependent attempts fail. An independent control case still proves. Neither a surviving RSP value nor a replayed receipt establishes the later return target.

### P2 — reachability, reuse and observability

11. **P2 · Reachability governs refusal — PRE-EXISTING whole-function CFG validation order.** R17:28–35 refuses before the walk, while `pcode_blocks.py:478–536` can reject unsupported operations before determining which blocks are reached.  
    **Rule.** Inventory row verdicts statically. Determine entry reachability from sound observed control flow before allowing a row-local S3 failure to refuse the function. An unknown edge that could reach the row prevents a dead-row finding. The candidate’s contradictory lifting, a downstream cut, or an assumed S3 return cannot prove it dead. A proven-dead row keeps its diagnostic and has no executed effect, writer, premise or refusal. A reachable unadmitted row refuses the whole function.  
    **Test.** Put a prefixed, contradictory, and unreadable row in turn after a terminal return. Preserve the earlier sink and report the dead row. Give that row a reachable predecessor, then a possible unresolved predecessor: each must prevent the dead-row exemption.

12. **P2 · Template eligibility and cache identity require evaluated closure evidence.** A dead kernel row has no placed support key, and a bundle-less ON run can produce none. Traversing published call names also need not identify the actual summary instance consumed. `summary_templates.py:216,260,334–355`, `interprocedural.py:704`, `linking.py:319,546`, `tools/derive_models/derive_models.py:143,167,213`.  
    **Rule.** An ON template requires complete static coverage and zero kernel rows in the producer and every summary instance it consumed, including cut, alternative and replay dependencies. Dead matches and indeterminate coverage bar export. Record effective switch, evaluation status, model identity and semantics version. Enforce compatibility in the shared importer, both profiles and both switch directions. OFF templates are OFF-only. Derivation must open the sealed original and instruction-block evidence independently of read-only value folding. Bind decision and analysis caches to those inputs, including loaded-block bytes, per-function observation and flow evidence.  
    **Test.** Reject export for a dead site in a transitive callee, unreadable coverage, and a bundle-less ON producer. Test both cross-switch import directions, explicit OFF in code-only, and a site-free ON round trip through derivation and linking. Change only loaded opcode bytes, override evidence, or model digest and require a cache miss.

13. **P2 · Stack escape and premise reports must agree with execution — PRE-EXISTING for unconditional stack-escape reporting.** Some stack-output queries omit the escaping-call set, and premise reporting can rescan raw trap operations. A placed site can consequently disappear from an escape report or acquire the wrong premise. `may_alias.py:1182,1334–1358`, `premises.py:241,282`, `summary_engine.py:936,980,1289–1305`.  
    **Rule.** Use the placed decision for stack escape, writer class, site kind and premise use in every report and analysis instance. Record the model file’s exact label, verified identity and canonical operation key. Carry that support to dependent roots, summaries and refinements. Teach callee-ID consumers to handle the synthetic ID without parsing an address. Check static verdicts even on failed functions and check effect, writer, escape and support together on placed sites.  
    **Test.** An admitted bare syscall with no explicit stack argument reports escape locally and through a wrapper, the RAM writer, `kernel-return` and the model label. It reports no raw LOCK/trap premise or synthetic function address. A dead row reports only its static verdict. A refused function reports its reason.

14. **P2 · Make refusal counts an actionable merge gate.** R17:33–39 predicts zero and requests counts, but a count can hide unreadable rows, overlap with K0, or classify valid code at a function boundary as a decode contradiction.  
    **Rule.** Report separate stable reasons for byte/lifting contradictions, unsupported encodings, unsupported flow contexts, and missing admission evidence. In particular, distinguish prefixed forms, listed exits, exception targets, nonlocal successors, missing S1/RSP/override evidence, and undecidable bytes. Count sites per reason and distinct refused functions, with deterministic primary reason and all contributing sites. Show dead diagnostics, unevaluated coverage and overlap with other refusal reasons separately. Run both profiles on the gate Bundles, ntdll, the field corpus and fixtures for both forms. Any nonzero stock-export refusal count goes to the owner before merge.  
    **Test.** Golden-report one function with multiple reasons, one dead failure, one undecidable ordinary row and one overlapping K0 refusal. Verify deduplication, coverage and explicit zeros. The ON/OFF diff must identify the affected function and reason.

15. **P3 · Define OFF equivalence and versioned exceptions.** An unqualified artifact identity check conflicts with deliberate proof, template and scanner changes. Subsystem 1 also includes kernel-mode images outside the user-mode contract. R17:70–73, `register_delta_proofs.py:76`, `summary_store.py:724`, `stack_evidence.py:37`.  
    **Rule.** Compare OFF semantic results against `18a5f5e` using regenerated, version-compatible gate artifacts. Enumerate permitted serialization, digest, version and report-metadata differences. Check values, debts, support, completeness, edges, refusals and proofs. Land independently applicable PRE-EXISTING fixes with their own measured baseline deltas so the S3 OFF comparison can isolate the switch. Version proof receipts, templates and clean scanner evidence. Keep OS-specific identity in model data and document a subsystem-native image executing in kernel mode as an explicit failure mode of the user-mode premise.  
    **Test.** Reject stale artifacts, regenerate and run the OFF differential in both profiles. Require every semantic difference to trace to a separately tested baseline fix. Verify both default-ON profiles resolve the pinned model and expose its documented label.
